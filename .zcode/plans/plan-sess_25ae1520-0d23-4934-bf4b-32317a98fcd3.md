## 实施目标

以桌面图标的蓝色为统一品牌锚点，保留编辑配置页现有深色结构；普通交互统一为蓝色，橙色只表示连接中/提醒，绿色只表示成功，红色只表示错误/危险。所有修改基于当前工作树做最小行级补丁，不恢复或覆盖已有未提交改动。

## 1. 建立统一主题色板

修改 `entry/src/main/ets/common/Theme.ets`：

- 将浅色品牌色调整为：
  - `PRIMARY = #1456B8`
  - `PRIMARY_DARK = #1E3862`
  - `ACCENT = #1F7EFA`
- 保留现有成功色 `#2E7D32`，并新增/整理语义 token：
  - `STATUS_CONNECTING`、`NOTICE_LIGHT` 使用 `#F5821F`
  - `STATUS_SUCCESS` 复用成功色
  - `STATUS_ERROR`/`DANGER_LIGHT` 复用现有危险红
- 调整深色品牌色：
  - `DARK_TOOLBAR = #1E3862`
  - `DARK_ACCENT = #30A0FC`
  - `DARK_ACTION = #1456B8`，用于深色页面的实心主要按钮
  - 保留 `DARK_BACKGROUND/#151B1C`、`DARK_SURFACE/#202829`、`DARK_SURFACE_ALT/#293233`、边框和文字色
  - 保留 `DARK_WARNING = #F5821F` 与 `DARK_DANGER = #FF7B7B`
  - 增加 `DARK_DANGER_SURFACE = #302122`
- 将主页状态卡片所需透明背景集中到主题中：连接中、成功、错误、空闲和通知背景，避免在 `ProfilesTab.ets` 内散落 alpha 字面量。
- 增加统一透明色 token，供本次涉及的透明输入框和 Tab 背景使用。

不修改桌面图标 PNG；图标的 `#1F7EFA/#30A0FC/#1E3862` 只作为界面主题的品牌参考。

## 2. 同步资源与文档

- 修改 `entry/src/main/resources/base/element/color.json`，将启动窗口背景从旧靛蓝同步为 `#1E3862`，避免启动瞬间与新主页工具栏产生色差。
- 更新 `README.md` 中的 Material 配色说明为新的品牌蓝、深蓝和亮蓝，并注明橙色为连接中/提醒色。
- 不修改 `_ref/ics-openvpn` 上游参考代码中的原始 Android 色值。

## 3. 统一主页的颜色语义

修改 `entry/src/main/ets/components/tabs/ProfilesTab.ets`：

- 普通 Profile 开关继续使用 `Theme.ACCENT`，因其已变为亮蓝。
- 连接中/重连状态改用 `Theme.STATUS_CONNECTING`，不再与普通开关共用品牌 token。
- 通知权限图标和边框改用 `Theme.NOTICE_LIGHT`。
- 连接中、已连接、认证错误、空闲和通知卡片背景改用 Theme 中的对应 alpha token。
- 主页工具栏以及其他通过 `Theme.PRIMARY` 引用的普通按钮会自动继承新的深蓝，不改变连接、导入和错误处理逻辑。

修改 `entry/src/main/ets/components/PrefRows.ets`：

- 浅色 `SwitchRow` 与 `CheckRow` 的选中态统一使用亮蓝 `Theme.ACCENT`。
- 深色开关、Checkbox 和分类标题统一使用 `Theme.DARK_ACCENT`。
- 保持文字、分隔线、禁用态和布局行为不变。

## 4. 统一编辑配置页和设置 Tab

修改 `entry/src/main/ets/pages/ProfileEdit.ets`：

- 移除页面顶部重复的硬编码暗色色板，改为引用 `Theme.DARK_*`。
- Checkbox、已保存状态、保存文字、 高级入口箭头使用 `Theme.DARK_ACCENT`。
- 深色工具栏使用 `Theme.DARK_TOOLBAR`。
- “设置连接快捷方式”和“添加代理”改为蓝色实心主要按钮（`Theme.DARK_ACTION` + 白字）；橙色不再承担普通操作语义。
- 删除卡片改用 `Theme.DARK_DANGER` 与 `Theme.DARK_DANGER_SURFACE`。
- 所有透明输入框改用统一透明 token。
- ProfileEdit 的密码 `InputDialog` 构造时显式传 `darkMode: true`，避免深色页面弹出白色输入框。

修改 `entry/src/main/ets/pages/VPNPreferences.ets`：

- 页面顶部重复的背景、工具栏、Tab 栏、文字和 accent 常量全部改为 `Theme.DARK_*` 引用。
- 保存文字、Tab 选中指示条和选中状态统一使用亮蓝 `Theme.DARK_ACCENT`。
- 未选中 Tab 的透明背景/分隔线改用统一透明 token。

修改仍保留硬编码暗色色值的设置 Tab：

- `entry/src/main/ets/components/settings/AuthTab.ets`
- `entry/src/main/ets/components/settings/IPTab.ets`
- `entry/src/main/ets/components/settings/RoutingTab.ets`
- `entry/src/main/ets/components/settings/ObscureTab.ets`

将背景、表面和边框映射到 `Theme.DARK_BACKGROUND/DARK_SURFACE/DARK_BORDER`；`BasicTab.ets`、`AllowedAppsTab.ets`、`ShowConfigTab.ets` 已有的 Theme 引用保持其现有结构，只随新 token 自动换色。

修改 `entry/src/main/ets/components/settings/ConnectionsTab.ets`：

- 深色 Toggle、Checkbox、Slider、FAB、启用标识继续使用新的 `Theme.DARK_ACCENT`。
- UDP/TCP 与代理类型的 Radio 增加 SDK 23 支持的 `radioStyle({ checkedBackgroundColor, uncheckedBorderColor, indicatorColor })`，消除系统默认色与深色页面不一致的问题；不使用不存在的 `selectedColor/checkedColor` API。
- 两处 `#302122` 改用 `Theme.DARK_DANGER_SURFACE`。
- 保留 `DARK_WARNING` 的自定义配置提示和 `DARK_DANGER` 的删除/无启用服务器语义，不把警告色误改成品牌蓝。

修改 `entry/src/main/ets/components/settings/AllowedAppsTab.ets`：

- 为预留的添加应用 `InputDialog` 显式传入 `darkMode: true`，防止该入口恢复后出现浅色弹窗；不改变当前未使用入口的逻辑。

修改 `entry/src/main/ets/components/InputDialog.ets` 与 `FileSelectRow.ets`：

- 让按钮颜色通过新的浅色/深色 action token 表达，视觉上与蓝色品牌色板一致；保留现有输入、取消、确认和文件选择行为。

## 5. 深色危险确认对话框

新增 `entry/src/main/ets/components/ConfirmDialog.ets`，不把无输入确认逻辑塞进已有的 `InputDialog`。组件提供：

- 标题、说明、取消/确认文案
- `darkMode` 和 `dangerous` 参数
- 单按钮/双按钮布局
- 深色表面、文字、边框、蓝色普通确认按钮，以及红色危险确认按钮
- `onConfirm/onCancel` 回调和可关闭的 `CustomDialogController`

将以下三个深色删除确认从原生 `AlertDialog.show` 迁移到该组件：

- `ProfileEdit.ets` 的删除 Profile
- `VPNPreferences.ets` 的删除 Profile
- `ConnectionsTab.ets` 的删除服务器连接

主页 `ProfilesTab.ets` 中的断开确认、配置错误提示和缺少配置项提示继续使用原生浅色 `AlertDialog`，但会自动继承新的 `Theme.PRIMARY`；这样避免扩大主页交互行为变化，同时修复本次目标中的深色页面跳色问题。
